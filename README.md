# Rádio Cometa FM

Site fictício de uma rádio online com visual inspirado nos anos 2000. 
Projeto desenvolvido para a disciplina de Tecnologia Web.

## Sobre o projeto
O site simula uma rádio da "era de ouro da internet", com direito a cores neon, fundos espaciais e referências nostálgicas ao Orkut, MySpace e Fotolog. O objetivo é colocar em prática os conceitos básicos de estruturação HTML e estilização com CSS.

## Páginas do site
- `index.html` - Página inicial com os destaques da rádio.
- `programacao.html` - Horários dos programas e a lista de estilos musicais.
- `pedidos.html` - Formulário interativo para os ouvintes pedirem músicas.
- `contato.html` - Formulário de contato e links para as redes sociais antigas.

## 🚀 Como abrir o site
Como o projeto utiliza apenas HTML e CSS puro, não é necessário instalar nada:
1. Baixe ou clone este repositório.
2. Certifique-se de que as imagens estão salvas dentro da pasta `img/`.
3. Dê um duplo clique no arquivo `home.html` para abrir no seu navegador.

## 📋 Requisitos do trabalho atendidos
- [x] **Imagem:** Uso da tag `<img>` na home, programação e contato.
- [x] **Link:** Menu de navegação `<a>` presente em todas as páginas.
- [x] **Lista:** Uso de `<ol>` (programação) e `<ul>` (estilos musicais e redes antigas).
- [x] **CSS Externo:** Estilização separada no arquivo `css/style.css`.
- [x] **Formulário:** Uso da tag `<form>` com inputs e validações nas páginas de pedidos e contato.
